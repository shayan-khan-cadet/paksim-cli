Features

🧠

Smart Mode

Type a number → auto-detects SIM vs CNIC → runs all relevant checks automatically.

📱

SIM / CNIC Lookup

Query all registered SIMs against any CNIC or phone number in one shot.

🧬

CNIC Structural Decode

Province → Division → District → Tehsil from the CNIC structure. 700+ entries.

📞

Phone Intelligence

Carrier, country, region, line type, timezone via Google libphonenumber.

👻

Ghost Mode

Route requests through anonymous proxies. Stay invisible while you research.

🗺️

Address Tracing

One-click Google Maps lookup for any address returned by the lookup.

💾

Query History

SQLite database of every lookup. Search, filter, export to CSV.

📄

HTML Reports

Generate beautiful dark-themed shareable reports for any lookup.

Installation

Terminal 
git clone https://github.com/shayan-khan-cadet/paksim-cli.git
cd paksim-cli
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 cli/paksim.py --help-commands

Usage

track 03239815518 Smart SIM lookup + phone intel
track 1610219061595 Smart CNIC decode + SIM lookup
track -g -s 03239815518 Ghost Mode (anonymous)
track --decode 16102-1906159-5 Structural CNIC decode
track --phone 03239815518 Phone intelligence
track -i Interactive mode
