Features

🧠

Smart Mode

Type a number → auto-detects SIM vs CNIC → runs all relevant checks.

📱

SIM / CNIC Lookup

Query all registered SIMs against any CNIC or phone number.

🧬

CNIC Structural Decode

Province → Division → District → Tehsil. 700+ entries.

📞

Phone Intelligence

Carrier, country, region, line type, timezone.

👻

Ghost Mode

Route requests through anonymous proxies. Stay invisible.

🗺️

Address Tracing

One-click Google Maps lookup for any address.

💾

Query History

SQLite database of every lookup. Search, filter, export.

📄

HTML Reports

Beautiful dark-themed shareable reports.

Installation

Terminal 
git clone https://github.com/shayan-khan-cadet/paksim-cli.git
cd paksim-cli
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 cli/paksim.py --help-commands

Usage

track 03000000000Smart SIM lookup + phone intel
track 0000000000000Smart CNIC decode + SIM lookup
track -g -s 03000000000Ghost Mode (anonymous)
track --decode 00000-0000000-0Structural CNIC decode
track --phone 03000000000Phone intelligence
track -iInteractive mode
